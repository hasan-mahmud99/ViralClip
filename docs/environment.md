# Environment variables

See `.env.example` for the full annotated list. Groups:

- AI: GEMINI_API_KEY, GEMINI_MODEL, GEMINI_MAX_RETRIES, GEMINI_RETRY_BASE_MS, GEMINI_CONCURRENCY
- YouTube discovery: YOUTUBE_API_KEY, YOUTUBE_SEARCH_QUERIES, YOUTUBE_MAX_RESULTS, YOUTUBE_LOOKBACK_HOURS
- Meta: META_ACCESS_TOKEN, META_PAGE_ID, META_API_VERSION
- Scheduling: DAILY_REEL_TARGET, PUBLISH_TIMES, TIMEZONE, APPROVAL_MODE, SOURCE_RIGHTS_POLICY
- Rendering: RENDER_WIDTH, RENDER_HEIGHT, SUBTITLES_ENABLED, SUBTITLE_STORAGE, RENDER_STORAGE
- Concurrency: TRANSCRIPTION_CONCURRENCY, RENDER_CONCURRENCY, PUBLISH_CONCURRENCY
- Auth: ADMIN_PASSWORD

Validate with `envSchema` in `@viralclip/shared`. Secrets must never be committed.
